# Gym dataset notice

The Palestra module uses the exercise metadata from [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset).

The repository contains 1,324 exercise records and is useful as a local searchable catalog. The non-media data is released under MIT. The exercise media is attributed to Gym visual and is subject to separate terms; the app ships metadata only and explicitly excludes the repository GIFs and thumbnails from the application target. See the bundled `Resources/GymDataset/NOTICE.md` before adding any media.

The app can later support licensed or self-hosted thumbnails through `image` and `gif_url`, without changing workout records. A download control must remain disabled until the project has an approved redistribution source and documents that license.
