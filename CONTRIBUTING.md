# Contributing

Thanks for considering a contribution to MyHealthData.

Start with [docs/contributing.md](docs/contributing.md). Before opening an issue or pull request, do not include real health records, screenshots containing personal health data, exported vaults, medical documents, or other sensitive personal information.

Useful local checks:

```sh
npm run lint
npm run test:run
npm run build
npm run oss:check
```

For iOS changes, also run the relevant Xcode build or test script documented in [docs/mobile/ios.md](docs/mobile/ios.md).
